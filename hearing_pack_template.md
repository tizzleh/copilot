# Hearing Pack Template

Fill this out for each specific hearing you want to run through Hearing Copilot. Keep the content concise and prefer bullet points. Add citations to any attachments you place in `./sources/` so the coach can reference them.

## Case Overview
- **Case name:** 
- **Jurisdiction / judge:** 
- **Proceeding type:** e.g., motion to dismiss, TRO, status conference
- **Hearing date (planned):** 

## Parties and Roles
- **Your role:** e.g., plaintiff pro se
- **Opposing counsel:** 
- **Judge preferences:** summarize demeanor, pacing, common questions

## Objectives
- 3–5 bullets that define what a “win” looks like for the hearing.

## Factual Background
- Timeline of key facts (short bullets, with dates if possible).
- Exhibits tied to each fact (include filenames in `./sources/` if you add PDFs).

## Legal Points
- **Primary authority:** controlling cases, statutes, rules (with pinpoint cites).
- **Supporting authority:** persuasive cases or secondary sources.
- **Counterpoints:** likely arguments from opposing counsel and your rebuttals.

## Motions / Requests
- **Relief sought:** the specific order(s) you want.
- **Key prongs/tests:** list required elements and how you satisfy each.
- **Fallback asks:** alternatives if the primary request is denied.

## Objections and Triggers
- Common objections you may need (e.g., leading, relevance).
- Judge-specific triggers (topics that draw questions or pushback).

## Logistics
- Time limits, order of argument, expected witnesses (if any).
- Links or filenames for pre-read materials.

## Prompts for Coach Cards
Provide short snippets you want the coach to watch for. Examples:
- "If opposing counsel claims lack of notice, remind me to cite Rule 12(b)(4) case law."
- "When judge asks about prejudice, surface the equitable factors list."

## Vocabulary / Acronyms
- Define any specialized terms the transcript might include.
